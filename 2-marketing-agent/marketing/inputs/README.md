# inputs/ — اللي بتبعته للـ Marketing Agent

| الملف | الاستخدام | الشكل |
|---|---|---|
| `comments-YYYY-MM-DD.txt` | كومنتات TikTok للـ Research | **كومنت في كل سطر**. عدد اللايكات اختياري بعد `\|` في آخر السطر (رقم صحيح فقط). الأسطر الفاضية بتتجاهل |
| `keywords.md` | الكلمات المفتاحية + الترندات اللي إنت بتبعتها | قسمين جوه الملف |
| `services.md` | خدمات Coder Nation (مرجع "مناسبة الفكرة للخدمات" وصحة المعلومات) | منقول من محتوى الموقع المؤقت. عدّله لما الخدمات تتأكد |
| `analytics.md` | **اختياري.** أوقات نشاط جمهورك، لتحسين وقت النشر | نص حر |

## مثال لملف كومنتات

```
كام سعر عمل موقع شركة؟ | 42
بتعملوا تطبيقات بـ Flutter؟
ينفع متجر إلكتروني على شوبيفاي ولا ديزاين من الصفر؟ | 17
```

## الفيديوهات
مش بتتحط هنا. الفيديو بيفضل في مكانه على جهازك، وبتديلي **المسار** في الشات وقت مرحلة المونتاج. الـ Agent بيقراه بـ ffmpeg ومبيعدّلوش.
